## Deployment

This is a static site. Drop the folder contents into the root of a GitHub Pages repository (username.github.io) or any static host. The site uses Bootstrap 5.3 and Google Fonts loaded from CDN, no build step required.

To preview locally:
```
python3 -m http.server 8000
```
Then open http://localhost:8000
